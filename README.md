# Basic Network Sniffer

## Description
A Python-based network sniffer developed using Scapy.

## Features
- Captures packets
- Displays source IP
- Displays destination IP
- Detects TCP and UDP protocols
- Shows packet size

## Technologies Used
- Python
- Scapy

## How to Run

pip install scapy

python sniffer.py
